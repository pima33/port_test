# MagerCam для Windows

Самостоятельное приложение для просмотра камеры нашего iOS MVP. Windows 10/11 x64, iPhone с MagerCam iOS 17+ и одна локальная сеть.

## Запуск

1. Распакуйте **весь** архив MagerCam-Windows-x64.zip в отдельную папку.
2. Запустите **MagerCam.Windows.exe**. .NET и библиотеки VLC включены в переносимую поставку; установка VLC и права администратора не требуются.
3. На iPhone откройте MagerCam и нажмите **Запустить камеру**.
4. В Windows введите IPv4 с iPhone, порт **4848** и шестизначный PIN. Нажмите **Подключить камеру**.

## Возможности

- Живое видео задней камеры: H.264, 1280 × 720, 30 fps, без звука.
- Подключение и отключение просмотра; автоматическое переподключение с интервалом 3 секунды.
- Статус, размер видео, частота поступления кадров, битрейт, число подключений и сообщение о нагреве iPhone.
- Полноэкранный просмотр: F11; возврат: Escape или F11.
- Запоминание IP, порта и выбора переподключения в `%LOCALAPPDATA%/MagerCam/connection.json`. PIN не сохраняется.

Оставляйте приложение iPhone открытым. Кнопка **Отключить** останавливает просмотр на ПК, а не камеру телефона. Перезапуск приложения iPhone меняет PIN. После неверного PIN, блокировки частых попыток или достижения лимита клиентов исправьте причину и подключитесь вручную.

Параметры камеры фиксированы в текущем iOS MVP. Управление зумом, фонариком, разрешением, микрофоном и записью пока не реализовано. Windows-клиент не создаёт виртуальное видеоустройство. Для OBS используйте существующий источник **MagerCam** с теми же IP, портом и PIN. Просмотр Windows и OBS допускается одновременно в пределах лимита iOS (4 клиента).

Видео декодируется программно. Приложение передаёт H.264 плееру через временный порт, доступный только на `127.0.0.1`; входящий доступ из LAN не открывается. HTTP/MC-соединение с iPhone не шифруется — используйте свою доверенную локальную сеть.

## Сборка

Нужен .NET 10 SDK на Windows:

```powershell
dotnet run --project windows/MagerCam.Tests -c Release
dotnet publish windows/MagerCam.Windows -c Release -r win-x64 --self-contained true -o build/windows/MagerCam-Windows-x64
```

Сборка использует LibVLCSharp.WinForms 3.10.2 и VideoLAN.LibVLC.Windows 3.0.24. Версии зафиксированы в проекте и lock-файле. Исходные библиотеки и лицензии перечислены в THIRD-PARTY-NOTICES.md.

## Проверка без телефона

`tests/fixture.h264` — сгенерированный тестовый ролик 720p30 (не запись камеры). Локальный сервер эмулирует HTTP/MC, SPS/PPS, keyframe, STATUS и разрывы TCP:

```powershell
python windows/tests/mock_camera.py
```

Подключитесь к `127.0.0.1:4848` с тестовым PIN `123456`. Для проверки восстановления используйте `--disconnect-after 5`. Для проверки отказа сервера — `--status 401`, `--status 429` или `--status 409`.

Проверки: фрагментированные HTTP/MC-пакеты, точные H.264-байты и timestamps, ошибки PIN/лимитов, повреждённый и слишком большой пакет, отмена соединения и декодирование тестового видео. Реальная задержка и совместимость с физическим iPhone требуют проверки на устройстве.
